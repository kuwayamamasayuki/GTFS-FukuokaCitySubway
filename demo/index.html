04 既製ツールで使う

標準 GTFS なので、世の中のツールにそのまま読み込めます。

ダウンロード

フィード本体と、地図ツール向けの GeoJSON。

⬇ feed.zip ⬇ network.geojson ⬇ trips.geojson

network.geojson は geojson.io / kepler.gl / QGIS にドラッグするだけで路線図に。 時刻つきの trips.geojson を kepler.gl の Trip layer に読み込めば 運行アニメーションが再生できます（→ 手順）。

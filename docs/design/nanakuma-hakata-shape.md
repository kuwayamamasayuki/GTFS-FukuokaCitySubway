# 七隈線 天神南～博多の形状注入 — Issue #55

## 背景と目的

参照データ `reference_gtfs/shapes.txt` は制作者本人の **2019 年版フィード**（七隈線が
天神南止まりだった延伸開業前のデータ）を `scripts/seed_reference.py` で取り込んだもの。
そのため七隈線の形状（`shapes.txt`）には**天神南～博多の区間が含まれていない**。

公開フィードでは博多まで形状を描けるようにしたい、というのが Issue #55 の要件である。
上流フィードには無いデータなので、取り込み時に `transform_shapes()` で**注入**する。

なお dir0 の `shape_id` は上流フィードでは「天神南方面行き」だが、延伸で終点が博多に
なったため、注入と同時に出力名を **`七隈線（博多方面行き）`** へ改称する（Issue #48）。
読み込みは上流名（`SHAPE_NANAKUMA_TM_SRC`）で行い、注入後に出力名へリネームする。
以降この文書では dir0 を出力名「博多方面行き」と呼ぶ。

- 駅間距離（`shape_dist_traveled`）＝福岡市地下鉄事業概要（令和7年度）の料金区界表
  <https://subway.city.fukuoka.lg.jp/subway/about/pdf/subway_all.pdf>
- 途中の座標＝OpenStreetMap

## 橋本方面行きが直感に反する点（重要）

`shapes.txt` の各形状の `shape_dist_traveled` は**その向きの起点からの累積距離**である。
向きが逆なので、橋本方面行き（`七隈線（橋本方面行き）`）では同じ物理区間でも
**起点が博多**に変わる。そのため単純な逆順コピーでは距離がずれる。注入は次の通り。

1. **先頭に前置**：博多方面行きの 8 点を**逆順**（博多→天神南）に並べ、`seq 0..7` を振る。
   各点の橋本側 `dist` ＝ `13600 −（天神南側 dist）`。
   → 博多 `0`, 350, 600, 650, 700, 750, 800, 1100。
2. **既存点をずらす**：もともと天神南（`seq 0`, `dist 0`）から始まっていた既存の全点を、
   `seq += 8`、`dist += 1600` する。`1600 ＝ 13600 −（天神南の dist 12000）`＝博多→天神南の距離。

前置末尾（博多方面行き seq113 相当, 橋本 dist 1100）と、ずらし後の旧先頭（天神南,
橋本 dist 1600）の差 500 は、博多方面行きの seq112→113 の距離 500 と一致し、区間は連続する。

## なぜソース（seed_reference.py）側に置くか

`reference_gtfs/shapes.txt` を直接手で編集すると、`seed_reference.py` を再実行した際に
上流 2019 フィード（博多区間なし）で**上書きされ消える**。`route_sort_order` や
`agency_fare_url` 等と同じく、取り込み時の `transform_*` として持たせることで再現性を保つ。
`transform_shapes()` は冪等で、既に注入済みなら二重追加しない。

検証は `tests/test_seed_shapes.py`。
